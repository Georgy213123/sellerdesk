# SellerDesk — инструкции для Claude Code

Рабочее место оператора продавца на маркетплейсах. Монорепо: `backend/` (FastAPI,
PostgreSQL), `frontend/` (React + TS, Vite), `e2e/` (Playwright).

## Перед началом

1. Прочитай `docs/03-design/architecture.md` и ADR, относящиеся к задаче.
2. Найди требование (`FR-NN`) и историю (`US-NN`), к которым относится задача.
   Если их нет, остановись и спроси.

## Команды

| Что | Команда |
|---|---|
| весь стенд | `make up` |
| локально | `make dev` |
| проверки | `make lint test` |
| e2e | `make e2e` |
| контракт | `make openapi` (после любой правки API) |

## Правила кода

- Внешние сервисы только через интерфейсы: площадки — `backend/app/marketplaces/`,
  LLM — `backend/app/llm/`. В тестах заглушки, сеть не нужна.
- Ленты и карточки читают данные только из БД: чтение площадок идёт фоновой синхронизацией,
  не из обработчика HTTP. Исключение — отправка ответа: её делает обработчик по действию
  оператора, с ключом идемпотентности.
- Ничего не уходит покупателю без действия оператора. Исключение — шаблонный автоответ,
  и то только если подставились все переменные. Иначе ответ сохраняется черновиком.
- Деньги и время: `Decimal` и `datetime` с часовым поясом (UTC в БД).
- Миграции только добавляют. Удаление колонки — отдельной задачей через ADR.

## Тесты

- Баг: сначала падающий тест, потом фикс. В docstring теста номер бага из `docs/06-bugs.md`.
- Новый эндпоинт: unit на сервис, интеграционный на API с PostgreSQL, контрактный тест.
- Изменение интерфейса: e2e-сценарий на двух вьюпортах (1440×900, 390×844).

## Нельзя

- Читать `.env*`, ключи и `secrets/`. Хук отклонит такой вызов.
- `git push`, `--force`, удаление веток. Это делает человек.
- Писать «готово», не запустив `make lint test`. В отчёте — вывод команд.
