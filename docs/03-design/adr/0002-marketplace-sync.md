# ADR-0002. Площадки за адаптером, синхронизация в свою БД

Статус: принято, 2026-10-21.

**Контекст.** Кабинеты отвечают секундами и с лимитами, API у трёх площадок разные. Если
интерфейс ходит в площадку на каждое открытие, оператор продолжит ждать.

**Варианты.** Прокси на каждый запрос; фоновая синхронизация в свою БД; вебхуки.

**Решение.** Синхронизация за интерфейсом `MarketplaceClient`, адаптер разбирает формат и время
площадки. Запись — upsert по внешнему id, повтор безопасен. Вебхуки есть не у всех площадок,
их можно добавить поверх.

**Последствия.** Лента не зависит от площадки, новая площадка — один класс. Данные отстают на
период синхронизации. Задача идёт в процессе API, для продакшена нужен воркер.
