# ADR-0003. Ключ идемпотентности для ответов покупателю

Статус: принято 2026-10-24, дополнено 2026-11-03 по ревью Codex.

**Контекст.** Ответ покупателю не отозвать. Двойной клик и ретрай после таймаута не должны
давать второй ответ.

**Варианты.** Только блокировка кнопки; дедупликация по тексту за N секунд; ключ от клиента.

**Решение.** Заголовок `Idempotency-Key` и уникальный индекс `(chat_id, idempotency_key)`,
плюс блокировка кнопки. Порядок: резерв строки → площадка → commit. Ключ передаётся и площадке, иначе потерянное подтверждение даёт дубль.
Тот же ключ с другим текстом — 409. Дедупликация по тексту съела бы законный повтор.

**Последствия.** Транзакция открыта на время вызова площадки: так проще и один ответ на ключ,
но при больших задержках нужен статус `sending`. Ответ на отзыв защищён условным UPDATE.
