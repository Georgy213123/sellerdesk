# Требования

MoSCoW. Тесты — в [05-testing.md](../05-testing.md).

## Функциональные

- FR-01 (Must). Площадки за интерфейсом `MarketplaceClient`, в демо заглушка.
- FR-02 (Must). Синхронизация в БД, upsert по внешнему id.
- FR-03 (Must). Единая лента по времени последнего сообщения в UTC.
- FR-04 (Must). Фильтры по площадке и статусу.
- FR-05 (Must). Карточка чата и ответ.
- FR-06 (Must). Отзывы и вопросы с фильтрами, ответ.
- FR-07 (Must). AI-черновик только сохраняется.
- FR-08 (Must). Шаблон с неподставленной переменной — черновик.
- FR-09 (Should). Вход по JWT.
- FR-10 (Should). Одна активная задача синхронизации.
- FR-11 (Could). Неизвестная переменная шаблона — 400.

## Нефункциональные

- NFR-01 (Must). Лента < 300 мс при задержке площадки 500 мс.
- NFR-02 (Must). Повтор и гонка не дают второго ответа.
- NFR-03 (Must). Текст покупателя только как текст.
- NFR-04 (Should). 390 px без горизонтальной прокрутки.
- NFR-05 (Must). Без ключей и сети; контракт и миграции сверяются с кодом.
