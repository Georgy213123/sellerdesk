# Требования

Приоритет — MoSCoW. Каждое требование проверяется тестом или e2e; матрица — в
[`../05-testing.md`](../05-testing.md).

## Функциональные

| ID | Требование | Приоритет | Критерий проверки |
|---|---|---|---|
| FR-01 | Площадки подключаются через единый интерфейс `MarketplaceClient`; в демо — заглушка `MockMarketplace` с детерминированными данными | Must | unit: заглушка детерминирована и удовлетворяет протоколу |
| FR-02 | Фоновая синхронизация переносит чаты, сообщения, отзывы и вопросы в БД; запись идемпотентна по (площадка, внешний id) | Must | повторная синхронизация не меняет число строк |
| FR-03 | Единая лента чатов всех площадок, сортировка по времени последнего сообщения в UTC | Must | лента упорядочена по убыванию; время площадок с разными зонами сравнивается верно |
| FR-04 | Фильтры ленты: площадка, статус (новый / в работе / отвечен) | Must | API и e2e: в выдаче только выбранная площадка |
| FR-05 | Карточка чата с перепиской и ответом; после ответа статус «Отвечен» | Must | e2e US-02 |
| FR-06 | Отзывы и вопросы: список, фильтр по типу, оценке и наличию ответа, ответ | Must | интеграционный тест фильтров, e2e US-04 |
| FR-07 | AI-черновик через интерфейс `LLMProvider`; черновик только сохраняется в карточке, отправляет оператор | Must | после запроса черновика площадка не получила ни одного сообщения |
| FR-08 | Шаблоны с переменными `{{buyer_name}}`, `{{product}}`, `{{order_number}}`, `{{marketplace}}`, `{{operator_name}}`; если переменная не подставилась — ответ не уходит, сохраняется черновик с причиной | Must | unit-тесты подстановки, e2e US-05 |
| FR-09 | Вход оператора по логину и паролю, JWT | Should | 401 без токена и с неверным паролем |
| FR-10 | «Обновить» ставит задачу и сразу отвечает; при активной задаче новая не создаётся | Should | 202 на новую задачу, 200 и тот же id на повтор |
| FR-11 | Справочник шаблонов: список и создание; неизвестные переменные отклоняются | Could | 400 на `{{nickname}}` |

## Нефункциональные

| ID | Требование | Приоритет | Критерий проверки |
|---|---|---|---|
| NFR-01 | Лента не ждёт площадку: ответ `/api/chats` < 300 мс при задержке площадки 500 мс | Must | `test_nfr01_feed_does_not_wait_for_marketplace` |
| NFR-02 | Один ответ покупателю на одно намерение: ключ идемпотентности обязателен, повтор и гонка не дают дубля | Must | `test_bug01_*`, unit-тест формы |
| NFR-03 | Текст покупателя выводится только как текст; `dangerouslySetInnerHTML` запрещён линтером | Must | unit и e2e BUG-04, правило ESLint |
| NFR-04 | Интерфейс работает на 390 px без горизонтальной прокрутки | Should | e2e на вьюпорте 390×844 |
| NFR-05 | Демо работает без ключей и без сети; настройки только из окружения | Must | весь набор тестов проходит офлайн |
| NFR-06 | Контракт API лежит в репозитории и совпадает с кодом | Must | `test_openapi_file_matches_code` |
| NFR-07 | Время хранится как `timestamptz`, API отдаёт UTC | Must | unit `test_timestamps.py`, API отдаёт `+00:00` |
| NFR-08 | Миграции совпадают с моделями | Should | `test_models_match_migrations` |
