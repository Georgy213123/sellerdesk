# Пользовательские истории

Роль во всех — оператор.

**US-01. Единая лента** (FR-03, FR-04, NFR-01), чтобы не обходить три кабинета.
- Given синхронизация прошла, When открываю «Сообщения», Then вижу чаты трёх площадок, свежие сверху.
- Given площадки пишут время в разных зонах, When смотрю ленту, Then порядок по реальному времени.

**US-02. Ответ в чате** (FR-05, NFR-02).
- Given я нажал «Отправить» дважды, When запросы дошли, Then покупатель получил один ответ.

**US-03. AI-черновик** (FR-07), отправлять только проверенное.
- Given открыт чат, When жму «AI-черновик», Then текст в поле, площадка ничего не получила.

**US-04. Отзывы** (FR-06, NFR-03), чтобы негатив не терялся.
- Given в отзыве HTML, When он показан, Then разметка видна как текст.

**US-05. Шаблон** (FR-08, FR-11), без `{{order_number}}` в тексте.
- Given у чата нет номера заказа, When отвечаю шаблоном, Then ответ не уходит, в поле черновик и причина.
- Given в шаблоне `{{Buyer_Name}}`, When он применяется, Then подставляется имя.

**US-06. Обновить** (FR-02, FR-10).
- Given синхронизация идёт, When жму «Обновить» ещё раз, Then вторая задача не создаётся.
