## [0.4.0] — 2026-11-04
### Добавлено
- Провайдер Claude API за интерфейсом `LLMProvider`, включается `LLM_PROVIDER=anthropic`; по умолчанию заглушка.
- Маскирование телефонов, e-mail и номеров заказов перед отправкой модели; имя покупателя в запрос не уходит.
- 503 `AI-черновик недоступен: <причина>` от эндпоинтов черновика; фронт показывает причину, оператор пишет ответ сам.
### Исправлено
- BUG-13: ответ с неподставленной переменной шаблона отклоняется сервером (422) и не отправляется из интерфейса.
- BUG-12: тесты работают только с базой `*_test` из `TEST_DATABASE_URL`, `make test` не трогает рабочую базу (guard `require_test_database`).
- Контракт: 401 у всех защищённых маршрутов в `openapi.yaml`.
### Безопасность
- `APP_ENV=production`: приложение не стартует с демо-секретом JWT или секретом короче 32 символов.
### Удалено
- Неиспользуемая dev-зависимость httpx2.
