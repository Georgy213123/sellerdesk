# 07. Путь к релизу

Версии — этапы сборки кейса: MVP, исправления по ревью, следующие круги ревью.

- **v0.1.0** — лента чатов, карточка, ответ. Отзывы отложил: сначала проверить «одну ленту».
- **v0.2.0** — отзывы, AI-черновик, фоновая синхронизация, вход. Шаблоны отложил: нужна безопасная подстановка.
- **v0.3.0** — шаблоны, идемпотентность, BUG-01…05, мобильная вёрстка, e2e.
- **v0.3.1–0.3.2** — 13 + 4 находки ревью Codex.
- **v0.3.3** — BUG-11, статус карточки после черновика.
- **v0.4.0** — Claude API за флагом, BUG-12 (защита тестовой базы, в том числе для reset), BUG-14, BUG-15, 401 в контракте, fail-closed JWT в production.
- **v0.5.0** — агент-маркетолог: автономный еженедельный прогон с чекпоинтом, бюджетом и арендой, 9 находок ревью Codex до коммита.
- **Unreleased** (текущая) — повторное ревью агента: 11 находок, 9 исправлены, 2 отложены.
- **v1.0.0** (план) — адаптеры реальных площадок, воркер, роли и журнал. Выход: каждая площадка
  синхронизируется неделю без потерь, первый ответ измеряется и ниже часа.

Заказы, возвраты и аналитика — после v1.0. История — [CHANGELOG.md](CHANGELOG.md).
