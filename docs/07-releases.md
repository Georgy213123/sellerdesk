# 07. Путь к релизу

| Версия | Что вошло | Что отложили и почему |
|---|---|---|
| **MVP (v0.1.0)** | лента чатов трёх площадок из заглушек, карточка, ответ; синхронизация командой CLI | отзывы — сначала проверить гипотезу «одна лента» на чатах; вход — рабочее место только локально |
| **v0.2.0** | отзывы и вопросы с фильтрами; AI-черновик через `LLMProvider`; фоновая синхронизация по кнопке; вход по JWT | шаблоны — нужна модель безопасности подстановки, вынесено в отдельную итерацию |
| **v0.3.2 (текущая демо)** | второй круг ревью исправления очереди синхронизации: гонка «конфликт → выборка», миграция на базе с дублями, оживление закрытой задачи, детерминированный тест гонки | — |
| **v0.3.1** | исправления по ревью Codex: 13 находок, из них BUG-06…BUG-10 — потерянное подтверждение площадки, поздний черновик в чужом чате, коллизия id после перезапуска, потеря правленого ответа, две задачи синхронизации | хранение ключей идемпотентности на стороне адаптера без поддержки ключа у площадки — вместе с настоящими адаптерами |
| **v0.3.0** | шаблоны с правилом «не подставилось — черновик»; идемпотентные ответы; исправлены BUG-01…BUG-05; мобильная вёрстка; e2e на двух вьюпортах; контракт OpenAPI сверяется тестом | настоящие адаптеры площадок — нужны ключи и тестовые кабинеты |
| **v1.0.0 (план)** | настоящие адаптеры с ретраями и учётом лимитов; отдельный воркер синхронизации по расписанию; роли и журнал действий | заказы, возвраты, остатки, аналитика — отдельные модули после v1.0 |

Критерии выхода v1.0:

- один реальный кабинет каждой площадки подключён и синхронизируется без потерь неделю;
- медиана первого ответа измеряется (модуль аналитики) и ниже 1 часа;
- журнал действий показывает, кто и что ответил.
