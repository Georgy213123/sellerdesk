# 01. Постановка задачи

## Контекст

«Северный свет» — вымышленный продавец светильников: настольные лампы, торшеры, потолочные
и настенные светильники, комплектующие. Около 20 позиций в каталоге, продажи идут через три
площадки: Wildberries, Ozon и Яндекс Маркет. Компания и все цифры ниже придуманы для кейса.

С покупателями работают два оператора. У каждой площадки свой личный кабинет со своими
разделами: чаты с покупателями, отзывы, вопросы о товаре.

## Боль

Операторы весь день переключаются между тремя кабинетами и отвечают вручную.

| Что происходит | Как это выглядит в цифрах (допущение) |
|---|---|
| Ответы опаздывают: новое сообщение видно, только если открыть нужный кабинет | медиана первого ответа — около 5 часов |
| Страницы кабинетов грузятся долго | 5–15 с на открытие списка, десятки открытий в день |
| Тон ответов разный: каждый оператор пишет по-своему | одинаковые вопросы получают разные ответы |
| Типовые ответы копируются из заметок, имя и товар правятся руками | ошибки подстановки: чужое имя, «{имя}» в тексте |
| Отзывы с низкой оценкой теряются среди положительных | часть негативных отзывов остаётся без ответа |

Цифры — правдоподобные допущения для постановки, а не измерения.

## Пользователи и роли

| Роль | Что делает | Что ему нужно |
|---|---|---|
| Оператор | отвечает в чатах, на отзывы и вопросы | одна лента, быстрые ответы, черновики, шаблоны |
| Старший оператор | следит за очередью, правит шаблоны | фильтр по статусу, справочник шаблонов |
| Площадка (внешняя система) | хранит чаты и отзывы, принимает ответы | — |
| LLM-провайдер (внешняя система) | предлагает черновик ответа | — |

В демо обе роли операторов работают под одной учёткой. Разделение прав — модуль «Роли и журнал
действий», в демо не входит.

## Критерии успеха

| Критерий | Целевое значение | Как проверяем в демо |
|---|---|---|
| Все обращения трёх площадок в одной ленте | 100 % чатов из заглушек | интеграционный тест синхронизации |
| Лента открывается быстро, не ожидая площадку | < 300 мс при задержке площадки 500 мс | `test_nfr01_feed_does_not_wait_for_marketplace` |
| Ответ уходит покупателю ровно один раз | 0 дублей при двойном клике и гонке запросов | `test_bug01_*`, unit-тест формы |
| Шаблон не уходит с неподставленной переменной | 0 случаев | `test_templating.py`, e2e US-05 |
| AI-черновик не уходит без оператора | 0 случаев | `test_us03_ai_draft_is_saved_not_sent` |
| Медиана первого ответа | с ~5 ч до < 1 ч | вне демо: нужна аналитика операторов |

## Вне рамок демо

- Заказы и отгрузки, возвраты и претензии, остатки и склады.
- Аналитика и показатели операторов, обмен с учётной системой.
- Роли, права и журнал действий.
- Настоящие API площадок и LLM: в демо только интерфейсы и заглушки.
- Вложения (фото) в чатах.
