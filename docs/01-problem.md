# 01. Постановка задачи

«Северный свет» — вымышленный продавец светильников на Wildberries, Ozon и Яндекс Маркете.
С покупателями работают два оператора, у каждой площадки свой кабинет. Цифры — допущения.

## Боль

- Новое сообщение видно, только когда оператор дошёл до нужного кабинета: первый ответ через ~5 часов.
- Список в кабинете открывается 5–15 с, открытий десятки в день.
- Типовые ответы копируются из заметок: бывает чужое имя или «{имя}» в тексте.
- Негативные отзывы теряются среди положительных.

Пользователи: оператор отвечает, старший оператор следит за очередью и правит шаблоны.
В демо у них одна учётка.

## Критерии успеха

- Все обращения трёх площадок в одной ленте.
- Лента < 300 мс при задержке площадки 500 мс (`test_nfr01_*`).
- Ответ уходит ровно один раз при двойном клике и гонке (`test_bug01_*`).
- Шаблон и AI-черновик не уходят без проверки (`test_templating.py`, `test_us03_*`).
- Первый ответ < 1 ч — вне демо, нужна аналитика.

Вне рамок: заказы, возвраты, остатки, аналитика, роли, вложения, настоящие API площадок и LLM.
