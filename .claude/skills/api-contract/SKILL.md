# Контракт API

1. **Контракт в репозитории.** `docs/03-design/openapi.yaml` выгружается из кода
   командой `make openapi`. Тест `test_openapi_contract` падает, если файл разошёлся с кодом.
   Выгрузил, посмотрел дифф контракта, приложил к PR.
2. **Совместимость.** Поле не удаляется и не меняет тип в той же версии. Новое поле
   либо необязательное, либо со значением по умолчанию.
3. **Ошибки** одним форматом: `{"detail": "..."}` (схема `ErrorOut`, описана в контракте), правильный
   HTTP-статус (400 — неверный ввод, 404 — нет ресурса, 409 — конфликт состояния, 422 — валидация).
4. **Идемпотентность.** Операции, которые что-то отправляют наружу, принимают
   `Idempotency-Key`. Повтор с тем же ключом возвращает тот же результат.
5. **Тесты на эндпоинт:** успешный путь, неверный ввод, нет ресурса, конфликт состояния.
   Интеграционные идут на настоящем PostgreSQL, не на SQLite.
